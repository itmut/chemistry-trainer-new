# Тривиальные названия — тренажёр по химии

Автономный статический сайт: исходники открываются и редактируются в VS Code, сервер или аккаунт ChatGPT для работы карточек не нужен.

## Запуск в VS Code

1. Откройте папку `chemistry-trainer`.
2. Установите расширение **Live Server**.
3. Откройте `index.html` → **Open with Live Server**.

Либо, если установлен Node.js/Python:

```bash
npm run build
npm run dev
```

После этого откройте `http://localhost:5173`.

Данные находятся в `data/chemistry.json`, а исходный манифест изображений сохранён в `data/organic_image_manifest.json`. Структурные рисунки органических веществ сохранены локально в `public/images/organic` в виде прозрачных SVG, поэтому карточки не зависят от внешнего сервера и остаются резкими при увеличении. Для полимеров добавлены отдельные карточки повторяющихся звеньев. Для добавления карточки достаточно изменить JSON и снова выполнить `npm run build`.

В тренажёре есть смешанный режим, отдельные разделы органики и неорганики, выбор режима перед стартом, случайная очередь с повтором ошибок до правильного ответа, статистика и восстановление активной сессии, кнопки «назад / сохранить / сбросить» и адаптивная мобильная верстка. В органике доступны три режима: «по формуле» (показывает только формулу и спрашивает тривиальное название), «по названию» (показывает название и спрашивает формулу) и «по рисунку» (показывает структурный рисунок и после ответа показывает название и формулу). Проверка не зависит от регистра, различий «е/ё», пробелов и вида нижних индексов; при вводе формулы она автоматически отображается заглавными буквами. В «Содержании» доступны компактный поиск, фильтр по классу и переключатель «рисунки / формулы» для органики; в представлении рисунков под каждым рисунком видны название и формула. Простые элементарные вещества (например, озон) исключены из тренировочной выборки, а полный список доступен в содержании.

## Публикация на GitHub Pages

Да, это статический сайт: сервер, база данных и аккаунт ChatGPT для работы не нужны. GitHub Pages отдаёт готовые HTML, CSS, JavaScript, JSON и SVG как обычные файлы.

1. Создайте новый репозиторий на GitHub и загрузите содержимое папки `chemistry-trainer` (файл `index.html` должен лежать в корне репозитория).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через минуту GitHub покажет ссылку вида `https://ваш-логин.github.io/имя-репозитория/` — её можно открыть на телефоне и добавить на главный экран.

Если публикуете папку `dist`, сначала выполните `npm run build`, а затем загрузите содержимое `dist` в выбранную ветку так, чтобы `index.html` оказался в корне публикуемой папки. Для работы карточек интернет не нужен: данные и картинки лежат в репозитории, а при отсутствии сети шрифт заменяется системным.
